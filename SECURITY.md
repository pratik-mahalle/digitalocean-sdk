# Security Policy

## Reporting a vulnerability

Please report security issues privately to Pratik Mahalle (https://github.com/pratik-mahalle).

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/pratik-mahalle/digitalocean-sdk/issues

## Scope

This policy applies to the generated Pratik Mahalle SDK packages published from this
repository (npm, PyPI, Packagist, RubyGems, LuaRocks, and the Go module).

This is an unofficial SDK for the DigitalOcean public API, generated by
Pratik Mahalle. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
